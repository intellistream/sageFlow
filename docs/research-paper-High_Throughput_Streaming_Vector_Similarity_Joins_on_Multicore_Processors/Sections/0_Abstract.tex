\begin{abstract}
Embedding-centric services increasingly require continuous streaming vector similarity joins, but most multicore join designs and vector indexing studies focus on static or batched settings where update and partition costs can be amortized offline. In sliding-window streams, systems must jointly handle high-rate ingest/probe traffic, boundary-sensitive candidate coverage, and skew-driven coordination overhead without violating window semantics. We present \system, implemented in \sageflow, which combines two-tier indexing for bounded-staleness read/write decoupling, budgeted boundary fanout routing over logical partitions, and an AssignmentTable-based rebalance control plane with RCU-style publication. Under evaluated workloads, the VSJoin path provides a favorable throughput--latency--quality operating region relative to baseline execution paths while keeping control overhead bounded. In our implementation, conclusions are scoped to tested settings, and we explicitly report degradation boundaries under high skew and tight fanout budgets.
\end{abstract}
